How is Loan EMI Calculated?

The Equated Monthly Installment (EMI) is computed using the standard reducing balance mathematical formula:

EMI = [P x R x (1+R)^N] / [(1+R)^N - 1]

Where P = Principal Loan Amount, R = Monthly Interest Rate (Annual Rate ÷ 12 ÷ 100), and N = Loan Tenure in number of months.
