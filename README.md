## 🔒 100% Client-Side Privacy Guarantee
Unlike standard utility websites that upload your private documents, sensitive photos, and financial data to remote servers, **AllToolsInOne processes 100% of files inside your browser's local memory** using modern WebAssembly, Canvas API, and HTML5 Web Workers. Zero server uploads, zero data harvesting.

## 🛠️ Tech Stack & Architecture
- **Frontend Core:** Semantic HTML5, Modular CSS3 Variables (Dark/Light mode)
- **Engine:** Vanilla JavaScript (ES6+), Web Workers, Canvas API
- **PDF Engine:** Client-Side PDF.js and pdf-lib
- **Image Processing:** In-browser Lanczos3 resampling and neural canvas filtering
- **SEO & Structured Data:** JSON-LD Multi-Layer Schema (@graph), RSS/Atom Feeds, Canonicalization
